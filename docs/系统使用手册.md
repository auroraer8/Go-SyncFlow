# Go-SyncFlow - 系统使用手册

> 版本：v3.5 | 更新日期：2026-02-25

本文档面向系统管理员，描述 Go-SyncFlow 统一身份管理平台的各功能模块操作指南。

---

## 1. 系统概述

Go-SyncFlow 是一套企业级统一身份管理平台，提供以下核心功能：

- **用户管理**：用户、角色、权限的集中管理
- **同步管理**：支持多种数据源的双向同步
- **单点登录**：支持 CAS、SAML、OIDC 协议
- **VPN 接入**：集成 VPN 用户认证与管理
- **安全中心**：登录安全、IP 管控、告警通知

---

## 2. 快速开始

### 2.1 首次登录

1. 访问系统地址：`http://<服务器IP>:8080`
2. 使用默认管理员账号登录：
   - 用户名：`admin`
   - 密码：`Admin@2024`
3. 首次登录后请立即修改密码

### 2.2 界面布局

- **顶部导航**：搜索、通知、个人中心
- **左侧菜单**：功能模块导航
- **主内容区**：功能操作界面

## 3. 用户管理

### 3.1 用户列表

**路径**：用户管理 → 用户列表

**功能**：
- 查看所有系统用户
- 支持按用户名、姓名、手机号搜索
- 支持按状态、角色筛选
- 支持批量操作

**操作**：
1. 点击「新建用户」创建用户
2. 点击用户行可查看/编辑详情
3. 状态开关可快速启用/禁用用户
4. 点击「重置密码」可重置用户密码

### 3.2 创建用户

**必填项**：
- 用户名（登录账号，唯一）
- 显示名称

**可选项**：
- 邮箱、手机号
- 所属角色
- 密码（不填则自动生成）

### 3.3 用户状态

| 状态 | 说明 |
|------|------|
| 正常 | 可正常登录使用 |
| 禁用 | 无法登录，保留数据 |

### 3.4 批量操作

- 批量启用/禁用
- 批量重置密码
- 批量分配角色
- 导出用户列表（Excel）

## 5. 同步管理

### 5.1 上游同步

**路径**：同步管理 → 上游同步

**功能**：从外部数据源同步用户到本系统

**支持的连接器**：

| 类型 | 名称 | 说明 |
|------|------|------|
| im_dingtalk | 钉钉 DingTalk | 从钉钉组织架构同步用户和部门 |
| im_wechatwork | 企业微信 WeChatWork | 从企业微信通讯录同步用户和部门 |
| im_feishu | 飞书 FeiShu | 从飞书组织架构同步用户和部门 |
| im_welink | WeLink | 从华为 WeLink 同步用户 |
| ldap_ad | Active Directory | 从 AD 域控同步用户 |
| ldap_openldap | OpenLDAP | 从 OpenLDAP 服务器同步用户 |
| db_mysql | MySQL | 从 MySQL 数据库同步用户 |
| db_postgresql | PostgreSQL | 从 PostgreSQL 数据库同步用户 |
| db_oracle | Oracle | 从 Oracle 数据库同步用户 |
| db_sqlserver | SQL Server | 从 SQL Server 数据库同步用户 |
| radius | RADIUS 服务器 | 通过 RADIUS 协议认证用户 |
| http_api | HTTP API | 通过自定义 HTTP 接口同步/认证用户 |

**配置步骤**：
1. 新建上游连接器，填写连接参数
2. 点击「测试连接」验证
3. 新建同步规则，选择连接器
4. 配置字段映射
5. 设置同步触发方式（定时/手动）

### 5.2 下游同步

**路径**：同步管理 → 下游同步

**功能**：将本系统用户同步到外部系统

**支持的连接器**：

| 类型 | 名称 | 说明 |
|------|------|------|
| ldap_ad | Active Directory | 同步用户到 AD 域控 |
| ldap_openldap | OpenLDAP | 同步用户到 OpenLDAP 服务器 |
| ldap_generic | LDAP 通用 | 同步用户到其他 LDAP 服务器 |
| db_mysql | MySQL | 同步用户到 MySQL 数据库 |
| db_postgresql | PostgreSQL | 同步用户到 PostgreSQL 数据库 |
| db_oracle | Oracle | 同步用户到 Oracle 数据库 |
| db_sqlserver | SQL Server | 同步用户到 SQL Server 数据库 |

**事件触发**：
- 用户创建时同步
- 用户更新时同步
- 用户删除时同步
- 密码修改时同步

### 5.3 字段映射

配置源字段与目标字段的对应关系：

```
示例：
源字段 displayName → 目标字段 cn
源字段 email → 目标字段 mail
源字段 phone → 目标字段 telephoneNumber
```

**转换规则**：
- `{{value}}`：直接使用原值
- `{{value | lower}}`：转小写
- `{{value | upper}}`：转大写
- `固定值`：直接填写固定值

## 6. 单点登录

### 6.1 应用管理

**路径**：单点登录 → 应用管理

**功能**：管理接入 SSO 的第三方应用

**创建应用**：
1. 点击「新建应用」
2. 填写应用名称、代码、描述
3. 选择支持的协议（CAS/SAML/OIDC）
4. 配置协议参数
5. 保存并获取接入参数

### 6.2 协议配置

**CAS 配置**：
- Service 白名单：允许的回调地址列表

**OIDC 配置**：
- Client ID：自动生成
- Client Secret：自动生成
- Redirect URIs：回调地址白名单
- Grant Types：authorization_code, client_credentials

**SAML 配置**：
- ACS URL：断言消费服务地址
- Entity ID：SP 实体标识
- 证书：自动生成或上传

### 6.3 权限管理

**路径**：单点登录 → 权限管理

**应用权限项**：定义应用侧的角色/权限值
**授权分配**：将权限项分配给本系统的角色或用户
**输出模板**：SAML 额外属性配置

### 10.4 密码代理

**路径**：系统设置 → 密码代理

**功能**：代理用户密码认证到外部系统，学习用户密码

**支持的认证源**：

| 类型 | 说明 |
|------|------|
| LDAP（AD/OpenLDAP） | 通过 LDAP 协议认证并学习密码 |
| 数据库 | 通过数据库查询认证并学习密码 |
| RADIUS | 通过 RADIUS 协议认证并学习密码 |
| HTTP API | 通过自定义 HTTP 接口认证并学习密码 |

**应用场景**：
- IM平台用户（钉钉/飞书/企微）无密码，通过代理认证学习密码
- 上游同步的用户（LDAP/AD/数据库/HTTP API）通过代理认证学习密码
- 用户首次登录从旧系统迁移密码

**密码学习机制**：
当用户本地无密码或密码验证失败时，系统会尝试通过配置的上游连接器进行密码代理认证。认证成功后：
- 本地密码将被更新为 bcrypt 格式
- 同时生成 SambaNTPassword 以支持本地 LDAP 服务
- 后续登录将直接使用本地密码验证，无需再次代理

> **注意**：上游同步不直接同步密码，密码统一通过密码代理功能学习。这样设计更安全且逻辑更清晰。

## 11. 常见问题

### 11.1 忘记管理员密码

1. 登录服务器
2. 使用重置脚本：
```bash
cd /opt/go-syncflow
./go-syncflow reset-password admin newpassword
```

### 11.2 同步失败排查

1. 检查连接器配置是否正确
2. 点击「测试连接」验证
3. 查看同步日志中的错误详情
4. 检查网络连通性

### 11.3 SSO 登录失败

1. 确认应用协议已启用
2. 检查 service/redirect_uri 白名单
3. 查看 SSO 登录日志
4. 确认账号在本系统存在

### 11.4 VPN 无法连接

1. 检查 VPN 服务状态
2. 确认用户组认证配置
3. 检查用户是否在允许的用户组
4. 查看 VPN 日志
