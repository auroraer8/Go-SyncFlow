# VPN 使用手册

## 一、概述

Go-SyncFlow VPN 是集成在用户管理平台中的企业级 SSL VPN 服务，支持 OpenConnect 协议，可用于安全的远程办公和内网访问。

### 1.1 主要特性

- **统一身份认证**：使用平台本地用户账号直接登录 VPN
- **细粒度访问控制**：基于用户组配置访问策略和路由规则
- **多重安全保障**：支持短信二次认证、使用范围限制
- **实时监控管理**：在线用户管理、连接日志审计

### 1.2 支持的客户端

| 平台 | 推荐客户端 | 下载地址 |
|------|----------|---------|
| Windows | Cisco AnyConnect / OpenConnect | [官网下载](https://www.cisco.com/c/en/us/support/security/anyconnect-secure-mobility-client/tsd-products-support-series-home.html) |
| macOS | Cisco AnyConnect / OpenConnect | App Store 或官网 |
| Linux | OpenConnect | `apt install openconnect` 或 `yum install openconnect` |
| iOS | Cisco AnyConnect | App Store |
| Android | Cisco AnyConnect | Google Play / 应用商店 |

## 二、管理员配置指南

### 2.1 服务配置

进入 **VPN 接入 → 服务配置** 页面：

#### 基础配置

| 配置项 | 说明 | 建议值 |
|-------|------|-------|
| 启用 VPN 服务 | 开关控制 VPN 服务启停 | 开启 |
| 监听地址 | VPN 服务端口 | 443 |
| 启用 DTLS | 启用 UDP 传输提升性能 | 推荐开启 |

#### 网络配置

| 配置项 | 说明 | 示例 |
|-------|------|------|
| 链路模式 | TUN（路由模式）或 TAP（桥接模式） | TUN |
| 主网卡 | 服务器出口网卡 | eth0 |
| IP 网段 | VPN 客户端分配的 IP 段 | 192.168.90.0/24 |
| 网关地址 | VPN 网关 IP | 192.168.90.1 |
| IP 范围 | 客户端 IP 分配范围 | 192.168.90.100 - 192.168.90.200 |

#### 连接参数

| 配置项 | 说明 | 建议值 |
|-------|------|-------|
| 最大客户端数 | 同时在线最大连接数 | 200 |
| 单用户连接数 | 同一用户最大同时连接 | 3 |
| 会话超时 | 连接自动断开时间（秒） | 43200（12小时） |
| 空闲超时 | 无流量自动断开时间（秒） | 3600（1小时） |
| 锁定时间 | 密码错误锁定时间（秒） | 300 |

### 2.2 用户组管理

进入 **VPN 接入 → 用户组** 页面：

#### 创建用户组

1. 点击「新增用户组」
2. 填写基本信息：
   - **名称**：用户组标识，如 `ops`、`dev`、`all`
   - **备注**：用户组说明

#### 认证配置

| 配置项 | 说明 |
|-------|------|
| 认证方式 | `syncflow` - 使用平台本地用户认证 |
| 短信二次认证 | 开启后登录需要短信验证码 |

#### 使用范围

限制哪些用户可以使用此用户组登录 VPN：

- **允许的用户**：指定具体用户
- **允许的部门**：指定部门下所有用户

> 如果两者都不设置，则该用户组允许所有本地用户使用

#### 网络策略

| 配置项 | 说明 | 示例 |
|-------|------|------|
| 允许局域网 | 允许访问客户端本地网络 | 通常关闭 |
| DNS 服务器 | 推送给客户端的 DNS | 8.8.8.8 |
| 包含路由 | 走 VPN 的目标网段 | 10.0.0.0/8, 192.168.0.0/16 |
| 排除路由 | 不走 VPN 的网段 | 根据需要配置 |

### 2.3 在线用户管理

进入 **VPN 接入 → 在线用户** 页面：

- 查看当前所有 VPN 在线用户
- 显示用户名、分配的 IP、连接时长、流量统计
- 支持强制踢出指定用户

### 2.4 日志查看

进入 **日志管理 → VPN 日志** 页面：

- **用户活动日志**：登录、登出、认证失败等记录
- **访问审计日志**：用户访问的目标地址记录

## 三、用户使用指南

### 3.1 获取连接信息

联系管理员获取以下信息：

- VPN 服务器地址（如：`vpn.company.com`）
- 您的用户名和密码（与平台账号相同）

### 3.2 Windows 客户端连接

1. 安装 Cisco AnyConnect Secure Mobility Client
2. 打开 AnyConnect，输入服务器地址
3. 点击「Connect」
4. 输入用户名和密码
5. 如启用短信验证，输入收到的验证码
6. 连接成功后，任务栏显示 AnyConnect 图标

### 3.3 macOS 客户端连接

1. 从 App Store 安装 Cisco AnyConnect
2. 打开应用，添加 VPN 连接
3. 输入服务器地址、用户名、密码
4. 点击连接

### 3.4 Linux 命令行连接

```bash
# 安装 openconnect
sudo apt install openconnect

# 连接 VPN
sudo openconnect https://vpn.company.com

# 输入用户名和密码后连接
```

### 3.5 移动端连接

1. 从应用商店安装 Cisco AnyConnect
2. 添加 VPN 配置，输入服务器地址
3. 连接时输入用户名和密码

## 四、常见问题

### 4.1 连接失败

**问题**：输入账号密码后提示"用户不存在或已停用"

**解决**：
1. 确认用户账号在平台中处于启用状态
2. 确认用户属于 VPN 用户组的使用范围
3. 联系管理员检查用户组配置

### 4.2 短信验证码收不到

**问题**：开启短信验证后收不到验证码

**解决**：
1. 确认手机号码正确
2. 检查短信通道配置是否正常
3. 查看系统通知渠道设置

### 4.3 连接后无法访问内网

**问题**：VPN 连接成功但无法访问内网资源

**解决**：
1. 检查用户组的「包含路由」是否包含目标网段
2. 检查服务器防火墙规则
3. 确认 NAT 转发已启用

### 4.4 连接不稳定

**问题**：VPN 经常断开

**解决**：
1. 启用 DTLS 提升连接稳定性
2. 调整会话超时和空闲超时参数
3. 检查网络质量

## 五、安全建议

1. **启用短信二次认证**：对敏感用户组强制开启
2. **限制使用范围**：仅允许需要的用户/部门使用 VPN
3. **定期审计日志**：检查异常登录和访问记录
4. **设置合理超时**：避免连接长期空闲
5. **限制单用户连接数**：防止账号共享
